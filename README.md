## 👥 Sistema de Gerenciamento de Clientes

**API REST para gerenciamento de clientes**, desenvolvida com Python e FastAPI.

### 🧰 Stack

```text
Python
FastAPI
PostgreSQL
SQLAlchemy
Pydantic
Uvicorn
```

### ⚙️ Funcionalidades

```text
[✓] Criar cliente
[✓] Listar clientes
[✓] Buscar cliente por ID
[✓] Atualizar cliente
[✓] Deletar cliente
[✓] Validação de dados
[✓] Tratamento de erros
[✓] Prevenção de e-mails duplicados
[✓] Documentação Swagger
```

### 📡 API

```text
GET     /clientes/
POST    /clientes/
GET     /clientes/{id}
PUT     /clientes/{id}
DELETE  /clientes/{id}
```
